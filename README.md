# 🐍 Coders Of Delhi

Coders Of Delhi is a pure Python data science project based on **CodeBook – The Social Media for Coders**.

The project focuses on loading, cleaning, structuring, and analyzing social-network data using only Python's built-in features, 
without using libraries such as Pandas or NumPy.

The project also implements basic recommendation systems for:

- 👥 People You May Know
- 📄 Pages You Might Like

---

## 🎯 Project Purpose

The main purpose of this project is to understand how raw social-network data can be processed and transformed into useful 
information using Python.

The project covers:

- Loading JSON data
- Understanding users, friends, and liked pages
- Cleaning and structuring messy data
- Handling missing values
- Removing duplicate data
- Removing inactive users
- Finding people based on mutual connections
- Recommending pages based on common interests
- Ranking recommendations using scores
